## Overview

Smarter Pie Menu reorganizes The Sims 4's interaction pie menu by removing redundant and rarely-used interactions, grouping similar actions into logical submenus, prioritizing frequently used interactions at the top level, and allowing players to customize which interactions appear based on personal play style preferences.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Smarter Pie Menu** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Menu Cleanup** | Removes rarely-used interactions that clutter the default pie menu |
| **Smart Grouping** | Groups related interactions into logical submenus for faster access |
| **Priority Sorting** | Frequently used interactions promoted to top-level for one-click access |
| **Customizable** | Configure which interaction categories appear and in what order |
